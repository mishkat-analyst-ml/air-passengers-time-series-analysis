# air-passengers-time-series-analysis
This project performs time series analysis on the Air Passengers dataset using Python. It explores passenger trends over time, identifies seasonal patterns, and visualizes yearly and monthly variations.  datetime conversion, feature engineering, and insightful visualizations using Pandas, Matplotlib, and Seaborn.

## 📌 Project Overview

This project focuses on performing Time Series Analysis on the classic Air Passengers dataset. The goal is to explore passenger trends over time, identify seasonal patterns, and visualize yearly and monthly variations using Python data analysis libraries.

## 📂 Dataset


The dataset contains monthly airline passenger counts, including:


Month (Date column)
Number of Passengers (#Passengers)


It is widely used for learning and practicing time series forecasting and trend analysis.



## 🛠️ Tools & Technologies

Python 🐍

Pandas

Matplotlib

Seaborn


## 📊 Key Steps Performed

Data loading and inspection (head, tail, info, describe)

Conversion of Month column into datetime format

Missing value check

Time-based feature extraction (Year, Month, Month_Number)

Yearly passenger trend analysis

Monthly average passenger analysis

Data visualization using bar plots and line plots



## 📈 Key Insights

Clear upward trend in air passengers over time

Strong seasonal patterns observed across months

Yearly growth shows consistent increase in air travel demand


## 📌 Visualizations Included

Time series line plot of passengers over time

Year-wise passenger distribution (bar chart)

Monthly average passenger trend (bar chart)


## 🚀 Conclusion


This project demonstrates how to handle and analyze time series data using Python. It helps in understanding trends, seasonality, and data transformation techniques essential for real-world data analysis and forecasting tasks.
